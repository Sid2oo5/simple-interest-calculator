# Simple Interest Calculator

## Description

A simple calculator to calculate Simple Interest based on the Principal Amount, Rate of Interest, and Time.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal Amount
* **R** = Rate of Interest
* **T** = Time

## Example

If:

* Principal = ₹10,000
* Rate = 5% per year
* Time = 2 years

Then:

```text
Simple Interest = (10000 × 5 × 2) / 100
                = ₹1,000
```

Therefore, the Simple Interest is **₹1,000**.

## Features

* Takes principal amount as input
* Takes rate of interest as input
* Takes time period as input
* Calculates simple interest using the standard formula
